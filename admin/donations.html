Moyens de paiement (prestataires officiels)

Sandbox = environnement de test du prestataire. Activez « live » uniquement pour les paiements réels.

Connectez ici les API officielles de vos prestataires (PayPal, Mobile Money RDC via opérateurs ou agrégateur agréé, passerelle carte bancaire). Tant qu'un prestataire n'est pas activé ET configuré, les dons en ligne restent désactivés côté public — aucun paiement simulé n'est possible.

Journal des paiements

La couche de paiement journalise automatiquement : création d'intention, initiation, webhooks reçus, confirmations et échecs (anti-double-paiement, idempotence, signatures vérifiées). Ces journaux sont la trace d'audit de chaque transaction.
